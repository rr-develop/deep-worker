## Key architectural differences

### 1. Level of abstraction
- **DeepAgents**: a low-level library for building agents (LangChain/LangGraph)
- **Claude SDK**: a client for interacting with a finished CLI (Claude Code)

### 2. Execution
- **DeepAgents**: in-process, everything runs in the same Python process
- **Claude SDK**: inter-process, the SDK talks to the Claude Code CLI via a subprocess

### 3. Extensibility
- **DeepAgents**: through the middleware pattern (ModelRequest/ModelResponse handlers)
- **Claude SDK**: through the hooks pattern (event callbacks) and MCP servers

### 4. File operations
- **DeepAgents**: through BackendProtocol (state, filesystem or sandbox)
- **Claude SDK**: through the built-in CLI tools (Read, Write, Edit, etc.)

### 5. Subagents
- **DeepAgents**: created as separate LangGraph graphs with their own middleware stack
- **Claude SDK**: defined via AgentDefinition, executed by the CLI

### 6. Sessions (in detail)
- **DeepAgents**: 
  - Use `thread_id` in `RunnableConfig`
  - Passed on invocation: `graph.invoke(input, config={"configurable": {"thread_id": "session-123"}})`
  - The checkpointer saves state by thread_id
  - Different thread_ids can be used for parallel conversations
  
- **Claude SDK**:
  - Use `session_id` as a query parameter
  - Passed on invocation: `await client.query(prompt, session_id="session-123")`
  - The CLI manages history and context by session_id
  - Supports `resume` for restoring a session and `fork_session` for branching
