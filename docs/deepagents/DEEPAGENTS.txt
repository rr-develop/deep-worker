    source ./venv/bin/activate

Then:
    user > Your question or request here
    agent > [AI response]
    user > quit

================================================================================
MAIN COMMANDS
================================================================================

Startup:
    deepagents-deepseek              # Main (Recommended)
    deepagents --model deepseek-coder # Code generation
    deepagents --model deepseek-reasoner # Complex tasks
    deepagents -r                    # Resume last session

Management:
    deepagents list                  # List agents
    deepagents threads list          # List sessions
    deepagents threads delete <ID>   # Delete session

================================================================================
API CONFIGURATION
================================================================================

Location: ./.env
Content:
    DEEPSEEK_API_KEY=<your-deepseek-api-key>
    GOOGLE_API_KEY=<your-google-api-key>
    AI_PROVIDER=deepseek

User config: ~/.deepagents/.env
    OPENAI_API_KEY=${DEEPSEEK_API_KEY}
    OPENAI_BASE_URL=https://api.deepseek.com
    OPENAI_MODEL=deepseek-chat

================================================================================
TROUBLESHOOTING
================================================================================

Q: Command not found?
A: Use full path or activate venv:
   source ./venv/bin/activate

Q: API key not working?
A: Check .env file and permissions:
   cat ./.env
   echo $DEEPSEEK_API_KEY

Q: Connection timeout?
A: Check internet and API status:
   ping api.deepseek.com

More help: See DEEPAGENTS_QUICKSTART.md
